# C Programming – University Exercises & Exam Preparation

---

## About This Repository

This repository documents my journey of learning the **C programming language** — starting from beginner fundamentals and gradually progressing toward advanced university exam-level problems.

The repository contains:
- basic syntax exercises
- algorithms and problem solving
- arrays and matrices
- strings and character manipulation
- functions and pointers
- structures (`struct`)
- dynamic memory allocation
- text and binary file handling
- filtering/searching/deleting systems
- mock exams and practical university tasks

Most exercises are self-solved for practice and revision purposes.
