Weekly C programming exercises and university tasks (organized by weeks)
# Week 03 – Arrays and Algorithms in C

## Overview
This repository contains solutions to Week 05 programming tasks in C.

The focus of this week is:

- Working with one-dimensional arrays
- Algorithmic problem solving
- Sequence analysis and transformations
- Index-based operations and logic

---

## Topics Covered

- Array traversal and manipulation  
- Finding longest sequences (equal, increasing, decreasing)  
- Array rotation (circular shift)  
- Searching for K-th element  
- Subarray sum problems  
- Insertion with shifting elements  
- Pattern validation in sequences  

---

## Implemented Problems

1. Find the longest plateau (sequence of equal elements) in a sorted array  
2. Check if a sequence follows the pattern: a0 < a1 > a2 < a3 ...  
3. Reverse an array  
4. Rotate an array by K positions (circular shift)  
5. Find the K-th largest element  
6. Find the longest increasing or decreasing subsequence  
7. Find a subarray with a given sum  
8. Insert elements at given positions (with shifting)  
9. Find the longest sequence of equal consecutive elements
