# Week 04 – Advanced Arrays and Matrices in C

## Overview
This repository contains solutions to advanced programming tasks in C.

The focus of this week is:

- Two-dimensional arrays and matrix operations
- Dynamic memory allocation
- Advanced array manipulation
- Algorithmic problem solving
- Searching and filtering techniques

---

## Topics Covered

- Matrix traversal and validation
- Row and column ordering checks
- Neighbor sum calculations
- Swapping rows in matrices
- Dynamic arrays
- Prime number filtering
- Submatrix problems
- Element insertion with shifting
- Searching and sorting logic
- Working with large datasets and relationships

## Concepts Practiced

- Nested loops
- Dynamic memory allocation (`malloc`, `calloc`, `free`)
- Matrix algorithms
- Array resizing and shifting
- Searching and filtering
- Index tracking
- Edge case handling
- Problem decomposition
