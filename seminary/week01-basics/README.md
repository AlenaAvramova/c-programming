# Week 01 – C Programming Basics

## Overview

This repository contains solutions to introductory programming tasks in C.

The goal of this week is to build a foundation in:

* Basic input/output
* Loops (for, while)
* Nested loops
* Simple problem solving using conditions and calculations

---

## Tasks

This repository includes various beginner-level exercises covering:

* Drawing shapes (frame, triangle)
* Working with loops and patterns
* Unit and temperature conversions
* Real-world calculation problems (area, capacity, etc.)

## Technologies

* Language: C
* Compiler: Code::Blocks
