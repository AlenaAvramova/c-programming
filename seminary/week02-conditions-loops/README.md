# Week 02 – Conditions, Loops and Problem Solving in C

## Overview

This repository contains solutions to Week 02 programming tasks in C.

The focus of this week is:

* Conditional statements (if / else)
* Loops (for, while)
* Problem solving with multiple conditions
* Working with edge cases and formatting

---

## Topics Covered

* Finding minimum and maximum values
* Time calculations and formatting
* Bonus systems with multiple rules
* Point position (geometry logic)
* Choosing optimal solutions (e.g. cheapest option)
* Working with ranges and percentages
