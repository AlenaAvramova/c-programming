# Exam Preparation Projects

---

## About

This folder contains larger university exam-style programming projects written in the C programming language.

The tasks focus mainly on:
- structures (`struct`)
- dynamic memory allocation
- text file handling
- binary file handling
- filtering/searching/deleting records
- working with dynamic arrays
- validation and error handling

All projects are based on real university mock exams and practical programming assignments.

---

### Main Concepts
- Dynamic memory allocation
- Filtering by weight and price
- Text and binary files
- Searching by unique code
