# Week 03 – Functions, References, and Number Logic in C

## Overview

This repository contains solutions to Week 03 programming tasks in C.

The focus of this week is:

* Functions
* Passing parameters by reference
* Working with digits of numbers
* Building logical problem-solving skills

---

## Learning Goals

* Understand how functions work in C
* Use pass-by-reference to modify variables
* Work with digits using `%` and `/`
* Build problem-solving patterns used in exams

* Understanding logic rather than memorizing solutions
