# Week 2: Iteration & Basic Algorithms

This folder contains C programming exercises focused on loops and basic numeric algorithms.

## Topics covered:
- Loops (for, while)
- Working with digits
- Fibonacci sequence
- GCD (Greatest Common Divisor)
- Number processing logic

## Exercises:
- Month and season
- Palindrome number
- Sum of multiples of 3
- Largest digit
- Numbers until zero
- Fibonacci numbers
- GCD function

Goal: Practice control flow and build problem-solving skills with basic algorithms.
