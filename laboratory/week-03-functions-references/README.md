# Week 3: Functions, References & Number Algorithms

This folder contains C programming exercises focused on functions, call by reference (pointers), and numeric problem-solving.

## Topics covered:
- Functions in C
- Call by reference (pointers)
- Working with digits
- GCD (Greatest Common Divisor)
- Prime number check
- Number processing logic
- Palindrome numbers

## Exercises:
- GCD function
- Prime number check
- Count digits
- Decimal to binary conversion
- Sum of digits
- Basic operations using references (sum, difference, product)
- Special number (digit sum and product conditions)
- Increasing digits check and modification
- Palindrome number (modify until palindrome)

## Goal:
Build a strong understanding of functions and references, and improve problem-solving skills using numeric algorithms.
